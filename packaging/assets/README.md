# Logo and icon

These files are in place; the build and the app pick them up automatically. To change the artwork, replace the files (nothing else needs editing):

| File | Used for |
|---|---|
| `packaging/assets/icon.ico` | the program icon of `ForzaPartTool.exe` (a multi-size .ico: 256, 128, 64, 48, 32, 16 px) |
| `toolkit/carbin_editor/logo.png` | the small mark in the app's header bar and the page icon (square PNG, at least 64 px) |
| `docs/images/logo.png` | the logo at the top of `README.md` |

If `icon.ico` or `logo.png` is missing, the app shows the name ForzaPartTool as text and the exe has the default icon.
