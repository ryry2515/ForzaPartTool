# Logo and icon

Put your own artwork here; the build and the app pick it up automatically (nothing else needs editing):

| File | Used for |
|---|---|
| `packaging/assets/icon.ico` | the program icon of `ForzaPartTool.exe` (a multi-size .ico: 256, 128, 64, 48, 32, 16 px) |
| `toolkit/carbin_editor/logo.png` | the small mark in the app's header bar and the page icon (square PNG, at least 64 px) |
| `docs/images/logo.png` | the README header, if you want one (add an `<img>` line at the top of `README.md`) |

Without these files the app simply shows the name ForzaPartTool as text and the exe has the default icon.
