Extract the whole ZIP, then run ForzaPartTool.exe.
Windows WebView2 Runtime is required. Python and an external browser are not needed.

1. In Settings, select your own FH1 game and DLC folder. Save paths & load cars.
   Xenia's title/content folder contains DLC, not the base game. If a valid base
   game is already saved, selecting that DLC folder keeps the game path and adds
   the DLC path automatically. Otherwise the editor explains which field to use.
2. Right-click a car in Cars and choose Import.
3. Click Custom model, then choose FBX, GLB, glTF or OBJ. GLB is best for embedded resources.
4. Position the orange model. Under "Where it goes" pick "as a separate part" (give it a name)
   or merge it into an existing part/upgrade slot. Add keeps the existing geometry;
   replace removes the target geometry. Driving + photo model is checked by default.
5. Check Double-sided if the model should be visible from both directions.
   This exports extra back faces in every chosen LOD. It doubles imported triangles.
6. Add to car. Apply to existing car saves all staged edits together, keeping the
   same car ID and making a .bak of the ZIP. Close Xenia first.
   GoD/ISO/STFS: Export car ZIP, then replace the archive in an extracted game/package
   copy. Set that extracted copy in Settings for future direct saves.
7. Export as new DLC car intentionally creates another car ID. Use it for a separate car.

Right-click parts or the orange model for Copy coordinates / Paste coordinates.
Right-click an existing part for Merge into. Named source slots remain when emptied.

Please test driving, photo mode, close-up views, and viewing the model from both sides.
Automated tests check the exported geometry and files; gameplay remains to be verified.
New shop-upgrade creation is not included yet. Existing upgrade slots are supported.
The viewport uses an approximation of FH1 materials. Separate cockpit/wheel files remain separate.
Importing modern (Forza Horizon 6) models and cars is not in this build yet.

Game files, saved paths and personal settings are not included in this ZIP.
Errors stay visible until dismissed. Use Copy error and the bug report template.
